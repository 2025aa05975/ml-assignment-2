# ML Assignment 2 - Classification Models

## Problem Statement
The objective of this project is to compare different machine learning classification models to predict whether a customer subscribes to a bank term deposit.

## Dataset Description
The Bank Marketing dataset is taken from UCI repository. It contains customer demographic and campaign-related features. The dataset has more than 45,000 records and 16 input features. The target variable indicates whether the customer subscribed (yes/no).

## Models Implemented
1. Logistic Regression
2. Decision Tree
3. K-Nearest Neighbors
4. Naive Bayes
5. Random Forest
6. XGBoost
